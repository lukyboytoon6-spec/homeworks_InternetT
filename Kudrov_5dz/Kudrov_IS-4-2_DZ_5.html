Современные языки программирования

Язык программирования C#

 Это объектно-ориентированный язык программирования общего назначения.
Разработан в 1998—2001 годах группой инженеров компании Microsoft под руководством Андерса Хейлсберга и Скотта Вильтаумота как язык разработки приложений для платформы Microsoft .NET Framework и .NET. Впоследствии был стандартизирован как ECMA-334 и ISO/IEC 23270. 		Статья про C#

Язык программирования Python

 Это высокоуровневый язык программирования общего назначения с акцентом на читаемость кода.
Создан Гвидо ван Россумом и впервые выпущен в 1991 году. Поддерживает несколько парадигм программирования, включая объектно-ориентированную, императивную и функциональную.
Широко используется в веб-разработке, анализе данных, машинном обучении и автоматизации задач. 		Статья про Python

Язык программирования Go

 Go (или Golang) — компилируемый, многопоточный язык программирования общего назначения.
Разработан в 2007–2009 годах в компании Google Робертом Гриземером, Робом Пайком и Кеном Томпсоном.
Создан для упрощения разработки высокопроизводительных и масштабируемых серверных приложений, с акцентом на простоту синтаксиса, быструю компиляцию и эффективную работу с конкурентностью. 		Статья про Go

Язык программирования Kotlin

 Kotlin — статически типизированный, объектно-ориентированный язык программирования общего назначения.
Разработан в 2010–2011 годах компанией JetBrains под руководством Андрея Бреслава как более лаконичная и безопасная альтернатива Java.
Работает на платформе JVM, полностью совместим с Java. С 2017 года признан Google официальным языком разработки для Android. 		Статья про Kotlin

Язык программирования Rust

 Это мультипарадигменный компилируемый язык программирования общего назначения.
Разработан Грэйдоном Хором в компании Mozilla Research, начиная с 2006 года; первая стабильная версия (1.0) выпущена в 2015 году.
Ориентирован на безопасность памяти, скорость и параллелизм: обеспечивает контроль доступа к памяти через систему владения и заимствования. 		Статья про Rust
