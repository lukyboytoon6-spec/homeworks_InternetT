Язык программирования C#

C# (произносится «си шарп») — объектно-ориентированный язык программирования общего назначения. Разработан в 1998–2001 годах группой инженеров компании Microsoft под руководством Андерса Хейлсберга и Скотта Вильтаумота как язык разработки приложений для платформы Microsoft .NET Framework и .NET.

C# сочетает в себе мощь C++ и простоту Visual Basic. Язык поддерживает строгую типизацию, сборку мусора, LINQ, async/await для асинхронного программирования. Впоследствии был стандартизирован как ECMA-334 и ISO/IEC 23270.

Сегодня C# применяется для разработки настольных приложений (WPF, WinForms), веб-приложений (ASP.NET), игр (Unity) и мобильных приложений (Xamarin).
